# VM-House

VM-House is a lightweight hypervisor designed for CoreX Kernel. A kernel project **made in turbowarp**.  
VM-House exists as part of an experimental kernel created with **TurboWarp**.

---

## How VM-House Works

VM-House runs **Scratch-based or Turbowarp-based OS projects** and later **converted into HTML**.
